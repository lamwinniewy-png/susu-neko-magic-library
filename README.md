# Susu 與 Neko 的魔法圖書館

給小學二、三年級小朋友的中文繪本網站。小朋友從魔法書櫃拿出魔法書，打開立體 pop-up 故事頁，學習新詞語。

- 5 本魔法書，共 75 個詞語，每本練習一個句式
- 4 個小遊戲：詞語配對、句子填充、聽音找詞、寫字練習（筆順）
- 粵語（裝置內置香港廣東話語音）及普通話（預錄小朋友聲音）朗讀
- 收集魔法星星與詞語寶盒

純靜態網站，直接打開 `index.html` 或以任何靜態伺服器提供即可。

筆順資料來自 [Make Me a Hanzi](https://github.com/skishore/makemeahanzi)，經 [Hanzi Writer](https://hanziwriter.org/) 顯示；香港學校寫法請以《常用字字形表》為準。
